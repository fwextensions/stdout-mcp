# Changelog

## [0.1.0](https://github.com/fwextensions/stdout-mcp/releases/tag/v0.1.0) (2026-11-20)

First release as `stdout-mcp`, replacing the `stdout-ext` package.

### Added

* An MCP server that lets coding agents read the logs, add markers, wait for new messages and reload the extension
* Logs are stored whether or not an agent is connected, including from more than one browser at once
* `stdout()` works from content scripts
